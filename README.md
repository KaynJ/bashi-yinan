# 八十一难 · 西游异世行记

剧情驱动的西游异世界队伍养成游戏试玩。浏览器中观看序章、在白骨岭布阵并自动战斗，跟随守护者的云形提示学习，再选择先追寻哪位失散的同伴。

[在线试玩](https://kaynj.github.io/bashi-yinan/) · [发布记录](https://github.com/KaynJ/bashi-yinan/actions)

## 当前内容

- 序章顺序：视频 1 → 2 → 3 → 4 → 白骨岭教学战 → 5 → 6 → 五涡选择。
- 首页六入口、三卷独立存档、导入导出、图鉴与设置。
- 自渡工作室 · River Yang。剧情先播放视频，再显示守护者文字对白。第 3、4 段共用一段对白，第 6 段末秒循环衔接同伴选择。
- 白龙马居中布阵、战中统计、白骨精入队动画。师徒五人对战白骨阵；逐格移动、双技能自动冷却、暂停、倍速与重试。
- 五涡选择记录先追寻的同伴，第一世界内容待续。

这是静态网页游戏。`web/` 内包含代码、图片、音频和六段经过网页压缩的视频，不依赖 ChatGPT Sites 运行。没有账号系统或云存档；每位玩家的数据保存在自己的浏览器中。

## 本地预览

安装 Node.js 20 或更新版本后，在仓库目录运行：

```sh
node preview.mjs
```

打开输出的本机地址。完整教学需要父页面访问战斗页，请通过 HTTP 预览，避免直接打开本地 HTML 时的跨页面访问限制。

## 更新和发布

推送到 `main` 后，GitHub Actions 先检查网页、素材、视频和存档规则，再发布 `web/`。发布状态以 Actions 与 Pages 的实际结果为准。

当前目录的 `sync.cjs` 用于作者本机：从工作区 `八十一难` 原项目同步发布资源，生成网页视频副本，不修改原片。外部克隆后也可直接编辑 `web/` 中的程序与素材。

```sh
node sync.cjs
npm test
git add .
git commit -m "更新游戏内容"
git push
```

网页使用相对路径，兼容 `/bashi-yinan/` 这样的 GitHub Pages 项目目录。存档兼容升级前应继续验证旧档迁移；更换浏览器、站点域名或清理数据前，可先导出存档。

视频和图片是独立资源，按游戏流程加载。供分享的小 HTML 文件只负责打开固定网址，后续更新可继续使用原入口。
